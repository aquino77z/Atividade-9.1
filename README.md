# Festival de Inverno de Mogi das Cruzes

Site estático sobre o Festival de Inverno de Mogi das Cruzes, com uma página inicial e uma página de detalhe do Parque Centenário da Imigração Japonesa.

Projeto da faculdade (ADS, Universidade Braz Cubas).

## Páginas

- `index.html`: página inicial com os locais em destaque
- `parque-centenario.html`: detalhes do Parque Centenário

## Tecnologias

- HTML5
- CSS3

## Como executar

Baixe os arquivos e abra o `index.html` no navegador. Não precisa instalar nada.
